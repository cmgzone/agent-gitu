THE WORK, NOT JUST THE ANSWER

Context first.
Confidence earned.

Give Gitu a repository and a clear outcome. Its coding workflow keeps the project, task state, and evidence close to the change.

01

Understand

Read the relevant files and the project’s instructions before changing the code.

02

Make the change

Work inside the selected project and keep the edit focused on the requested outcome.

03

Check the result

Run meaningful tests or checks. Failed checks remain visible and inform the next action.

04

Show the work

Review the changes, supporting results, and limitations before deciding what to ship.
