Right account.
Right teammate.

Use Composio for supported connected services, or configure a native mailbox. Available integrations and actions depend on your provider and account.

01

Connect

Sign into the service through its supported connection flow. Sign-in stays with you.

02

Assign

Choose which teammate can use the connected account. Another agent does not inherit that access.

03

Allow

Review the requested action. Give a one-time approval or allow that exact tool for the assigned account.

04

Use

Ask the teammate for an outcome. It uses the permitted tools and reports the result.

SMALL REQUEST. DIRECT ANSWER.

“How many unread
emails do I have?”

A count request should stay a count request. Gitu is guided to use the smallest sufficient read, reuse successful results, and answer when the evidence is available.

When a provider returns thread counts or estimates, the agent should explain that distinction instead of presenting an unsupported exact email count.

Suggestions with context

When enabled, permitted reviews can combine app evidence, recent requests, and shared preferences to identify useful next steps.

Reviews while idle

Eligible background app reviews are spaced about six hours apart and defer when the agent is working in another chat.

Useful boundaries

Background app reviews use previously allowed read tools. A recommendation is not permission to perform an external action.
