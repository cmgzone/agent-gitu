Prefer the source?
Make it yours.

The current source version is 0.3.12. Published installers may follow a different release schedule; GitHub lists the version and assets available to download.

The software is MIT licensed. Model usage, subscriptions, connected services, and hosting can have separate costs.

Build from source
Build the current source
git clone https://github.com/cmgzone/agent-gitu.git
cd agent-gitu
npm install

Choose your permissions

Keep the runtime available

For local scheduled work, keep the application running and your computer awake and connected.

Need a hand getting started?

Follow the setup guide or report a concrete problem in the repository. Include what you expected and what happened; leave credentials and private messages out of issue reports.
