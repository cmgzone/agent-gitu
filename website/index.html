What it does

One agent, three ways to work

Every surface shares one project lock and one evidence gate, so work done in the terminal is visible in the desktop app and in your teammates' threads.

Coding

Investigate a real repo, make the edit, and prove it with the project's own test command.

  • Reads symbols before touching code
  • Small reversible changes, one at a time
  • Refuses success without a passing check
Explore coding

Cowork

Put named teammates on one goal and follow every thread they open while they work.

  • Teammates with distinct roles
  • Threaded updates, not a wall of logs
  • Shared connections to your tools
